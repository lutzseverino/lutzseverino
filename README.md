## What I'm building

Developer tooling for working with AI coding agents. I designed and built all of
it with AI coding agents, mostly Claude Code and Codex.

| Project | What it does |
| --- | --- |
| [Repo Standards](https://github.com/lutzseverino/repo-standards) | Write your setup down once, and your coding agent applies it to every repository: agent instructions, docs, templates and checks, kept in step by versioned updates. [repo-standards.com](https://repo-standards.com) |
| [Repo Canon](https://github.com/lutzseverino/repo-canon) | A ready-made setup to adopt with Repo Standards: AGENTS.md, agent skills, contribution guidelines, issue and PR templates, and checks. |
| [Scriptorium](https://github.com/lutzseverino/scriptorium) | A self-hosted service that implements ready GitHub issues with coding agents in sandboxes, on your own machine. |
| [Postern](https://github.com/lutzseverino/postern) | A Node.js library that gives tool builders one interface to code hosting platforms such as GitHub. |
| [governance-skills](https://github.com/lutzseverino/governance-skills) | Agent skills for implementation decisions and React component architecture. |
| [receiver](https://github.com/lutzseverino/receiver) | The source of [lutzseverino.com](https://lutzseverino.com), my personal site, built as a radio receiver you tune between channels. |
